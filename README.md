# pimple — MVP (educacional/portfolio)

App educacional que **triagem de risco** de pintas a partir de **imagem + metadados** (sexo, localização anatômica, idade opcional).  
⚠️ **Não é diagnóstico médico**. Uso privado para aprendizado/portfolio.

## Objetivo do MVP
- Fluxo simples: **Home → Enviar foto → Questionário (sexo/localização/idade) → Analisando → Resultado**.
- Saída: **probabilidade** + **nível de risco (baixo/incerto/alto)** + **disclaimer**.
- **Histórico local** de análises.

## Escopo (MVP)
✅ 1 imagem por caso • ✅ sexo + localização • ✅ idade opcional • ✅ histórico local  
❌ login/conta • ❌ nuvem/telemedicina • ❌ laudo clínico • ❌ explicabilidade avançada
