# Testes Manuais — MVP

## Fluxo principal
- [ ] Home abre e mostra disclaimer
- [ ] Upload/câmera seleciona 1 imagem
- [ ] Questionário aceita sexo/local/idade e valida obrigatório
- [ ] Analisando exibe loading e trata “voltar”
- [ ] Resultado mostra prob, nível e disclaimer

## Erros/comportamentos
- [ ] Imagem inválida → mensagem clara
- [ ] Campos vazios obrigatórios → alerta claro
- [ ] Histórico local salva e lista resultados
- [ ] Limpar histórico remove dados sem crash

## Acessibilidade/UX
- [ ] Fonte legível, contraste suficiente
- [ ] Botões com rótulos claros
- [ ] Fluxo em ≤ 3 toques
