# Visão de Produto — pimple

**Para:** aprendizado e portfolio.  
**O que:** triagem de risco de lesões cutâneas (pintas) baseada em imagem + metadados.  
**Valor:** mostrar domínio do ciclo completo: dados → modelo → app → responsabilidade/ética.

## Problema
Pessoas têm dúvidas sobre pintas; modelos de visão podem priorizar atenção. Em ambiente educacional, isso vira um exercício completo de ML + produto.

## Solução (MVP)
- Captura/Upload de imagem
- Questionário rápido: sexo, localização (dropdown), idade (opcional)
- Probabilidade + nível de risco + histórico local + disclaimers

## Sucesso (MVP)
- Fluxo completo rodando localmente
- Notebook de EDA/treino reprodutível em amostra
- UI com 5 telas, contrato de API estável, logs básicos
